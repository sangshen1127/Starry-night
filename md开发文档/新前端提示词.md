全局设定与核心风格
你是一个资深前端工程师兼二次元视觉设计师。请参考 GitHub 上 Kirameku、XinghuisamaBlogs、Hexo Butterfly Glass 等开源博客的视觉语言，重构当前页面。目标是二次元动感 + 毛玻璃通透感 + 暗色沉浸感。

核心关键词：二次元（Anime）、玻璃拟态（Glassmorphism）、毛玻璃、半透明层叠、霓虹微光、粒子/星尘、柔和圆角。

整体氛围：保持暗色基调，但用二次元的高明度色彩点缀，避免过于冷硬。页面像浮在星空或少女漫背景上的“玻璃卡片群”。

设计系统（Design Tokens）
色彩（Color Palette）

背景基底：不要纯黑。使用深紫蓝或深空灰（如 #0f0c1b / #12101e），并叠加一层低透明度的二次元背景图（星空、樱花、角色半身剪影均可，模糊处理），让玻璃有东西可以“透”。

二次元强调色：采用高饱和但不刺眼的动漫色系——樱粉 #ff9eb5、天青 #7ec8e3、电光紫 #b967ff。主按钮和关键高亮使用其中的渐变（如 linear-gradient(135deg, #ff9eb5, #b967ff)）。

文字色：主文字用 rgba(255,255,255,0.92)，次要文字用 rgba(255,255,255,0.55)，在暗色玻璃上保持可读性。

玻璃材质（Glassmorphism Stack）
所有卡片、导航栏、侧边栏、按钮统一使用以下玻璃参数，禁止使用纯色实心背景：

背景：background: rgba(255, 255, 255, 0.06)（暗色模式下可微调至 0.04–0.10）。

模糊：backdrop-filter: blur(16px) saturate(140%)（Kirameku 同款参数，兼顾磨砂与色彩饱和度）。

边框：border: 1px solid rgba(255, 255, 255, 0.12)，模拟玻璃边缘的高光。

阴影：box-shadow: 0 8px 32px rgba(0, 0, 0, 0.35)，让玻璃有浮起感。

圆角：border-radius: 20px（大卡片可用 24px，按钮/标签用 12px）。

字体与排版

中文标题：优先使用圆体/漫画体（如 ZCOOL KuaiLe、Ma Shan Zheng 或系统圆体），字号拉开差距（H1 48–56px，H2 32px）。

英文/数字：搭配 Quicksand 或 Nunito，保留一点几何感，避免过于严肃。

装饰元素：可在标题旁添加小型 SVG 星星、心形、猫爪或日文假名点缀（如 ✦ ♡ にゃ）。

页面结构与组件改造
顶部导航栏（Navbar）

整条导航使用玻璃条：半透明背景 + backdrop-filter: blur(20px)，边框只保留底部一条微光 border-bottom: 1px solid rgba(255,255,255,0.08)。

Logo 区域可替换为一个小尺寸二次元头像/圆形角色图标，旁边保留 “START NIGHT” 文字。

导航链接 hover 时，文字渐变为樱粉→电光紫，并出现一条微光下划线（text-shadow 轻微发光）。

首屏 Hero 区域（最关键）
当前深色实心大卡片 → 改为全屏或 70vh 的背景图层：

底层：二次元背景图（星空/角色），用 filter: blur(2px) brightness(0.6) 压暗。

上层叠加两个玻璃面板：

左侧文字玻璃卡：放置标题“把每一个夜晚，写成一点光。”以及副文案。标题文字使用白色 + 微弱粉色发光（text-shadow: 0 0 20px rgba(255,158,181,0.3)）。按钮组改为胶囊玻璃按钮，主按钮填充樱粉→电光紫渐变，次按钮为透明玻璃带边框。

右侧角色立绘卡：当前月牙区域替换为二次元角色半身插画（或高质量立绘），卡片本身是玻璃框，内部图片可加 mask-image 渐变淡出边缘，避免生硬裁切。

卡片角落可添加日文竖排装饰文字（如「夜の記録」「きらめく」），使用小号、低透明度，增加二次元排版感。

最新文章卡片（Latest Notes）

每张文章卡都是独立的玻璃小块（border-radius: 16px），hover 时：transform: translateY(-4px) scale(1.01)，同时边框微光增强。

卡片左侧可放圆形二次元缩略图（角色/Q版表情），右侧是标题 + 摘要 + 日期。

标签（Tag）使用半透明彩色小胶囊（如 rgba(185,103,255,0.15) 背景 + 紫色文字）。

关于小屋侧边卡（About）

改为垂直玻璃卡，内部头像加一个旋转的虚线圆环或发光光晕（box-shadow: 0 0 24px rgba(185,103,255,0.4)）。

背景可添加一层极淡的二次元网点纹理（CSS radial-gradient 重复小点），增加漫画感。

动效与交互（二次元灵魂）
粒子/星尘背景：在页面最底层（z-index: 0）注入 particles.js 或纯 CSS 动画，飘落樱花花瓣 / 星星 / 光点，透明度 0.3–0.5，移动速度缓慢。

鼠标跟随光晕：在玻璃卡片上，鼠标移动时产生一个微弱的径向渐变光斑（通过 radial-gradient + pointermove 事件更新坐标），模拟玻璃的反光。

入场动画：首屏文字和卡片使用 framer-motion 或 CSS @keyframes 实现交错上浮淡入（staggered fade-in-up），每张卡片延迟 0.1s。

悬停微动效：按钮 hover 时轻微放大（scale(1.03)）并增强发光；玻璃卡片 hover 时边框从 rgba(255,255,255,0.12) 过渡到樱粉/紫色微光。

响应式与可访问性
移动端：首屏右侧角色立绘可隐藏或缩小为头像，玻璃卡片宽度自适应 calc(100vw - 32px)，圆角略减小（16px）。

玻璃背景透明度在移动端可略微提高（rgba(255,255,255,0.10)），确保小屏阅读对比度。

所有玻璃卡片内的文字对比度须满足 WCAG AA（可通过在玻璃层下方加一层极暗遮罩实现）。
