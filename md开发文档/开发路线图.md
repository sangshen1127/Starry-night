## 1. 先花 10 分钟修正三处

这是当前代码里已经存在的问题，越早改越省事。

### 1.1 Security 只放行了 `/api/test`

`SecurityConfig` 里写的是 `requestMatchers("/api/test", "/error")`。这意味着你下一个接口 `/api/posts` 一写出来就是 401。

两个选择：

- **现在改**：放行 `/api/**`（登录功能做完后再收窄）
- **以后每加一个接口就加一条**：更精确，但容易漏

建议现在改成 `/api/**`，等 M2 做完登录再把 `/api/admin/**` 单独提出来。

### 1.2 方法签名里有个没用的参数

```java
securityFilterChain(HttpSecurity httpSecurity, ConfigurableWebServerFactory configurableWebServerFactory)
```

第二个参数从头到尾没用到，对应的 `import` 也可以删。它不影响运行，但会让读代码的人以为这里有什么特殊用途。**没用的东西就删掉**，这是整洁代码的第一步。

### 1.3 返回体字段名和接口文档不一致

你的 `Result` 里字段叫 `msg`：

```java
private Integer code;
private String msg;
private Object data;
```

接口文档里约定的字段是 `message`。

**必须二选一，现在定死：**

| 方案 | 做法 | 影响 |
|---|---|---|
| A（推荐） | 把 `msg` 改成 `message` | 代码改一个词，文档不动 |
| B | 把文档里的 `message` 全改成 `msg` | 文档改 20 多处，以后对接第三方接口时容易被 `message` 带偏 |

推荐 A。改的时候注意：`success()` 和 `error()` 里给 `msg` 赋值的地方也要一起改，Lombok 生成的 getter 会跟着变。

## 4. 详细任务

### M1 打通数据链路（2～3 天）✅ 已完成

> 目标：浏览器访问 `/api/posts`，返回的是 MySQL 里真实存着的文章。

#### T1.1 加 MyBatis-Plus 依赖

- [x] 在 `pom.xml` 加两个坐标：
  - `mybatis-plus-spring-boot4-starter`，版本 `3.5.17`
  - `mybatis-plus-jsqlparser`，版本 `3.5.17`（分页插件依赖它）
- [x] Reload Maven，确认没有红色报错

**验收**：`External Libraries` 里能看到 `mybatis-plus-*`，启动不报错。

**常见坑**：加成了 `mybatis-plus-boot-starter`（那是 Boot 3 的），启动会报找不到类。

#### T1.2 写 Post 实体

- [x] 建包 `com.sangshen.entity`
- [x] 类 `Post`，字段和 `posts` 表一一对应
- [x] `@TableName("posts")` 指定表名
- [x] `@TableId(type = IdType.AUTO)` 指定自增主键
- [x] 时间字段用 `LocalDateTime`

**验收**：启动不报错（此时还没用到它，正常）。

#### T1.3 写 PostMapper

- [x] 建包 `com.sangshen.mapper`
- [x] 接口 `PostMapper extends BaseMapper<Post>`
- [x] 在启动类上加 `@MapperScan("com.sangshen.mapper")`

**验收**：启动不报 "找不到 Mapper" 之类的错。

**常见坑**：忘了 `@MapperScan`，启动直接失败，提示找不到 `PostMapper` 的 Bean。

#### T1.4 第一个真实接口

- [x] 建 `PostController`，`GET /api/posts`
- [x] 调 `postMapper.selectList(...)`，只查 `status = 'published'`，按 `published_at` 倒序
- [x] 用 `Result.success(list)` 包装返回

**验收**：浏览器访问 `/api/posts`，看到的是你在 Navicat 里手动插的那两条数据。

**这一步是整条链路的验证点**：请求 → Controller → Mapper → MySQL → JSON。通了，你就掌握了后面 20 多个接口的模板。

#### T1.5 分页

- [x] 加 `page`、`size` 参数，默认 1 和 10
- [x] 配 `MybatisPlusInterceptor` + `PaginationInnerInterceptor(DbType.MYSQL)`
- [x] 返回 `{ list, total, page, size }`

**验收**：`?page=1&size=1` 只返回一条，`total` 还是总数。

#### T1.6 统一异常处理

- [x] 建 `common` 包，写 `GlobalExceptionHandler`，加 `@RestControllerAdvice`
- [ ] 处理参数校验异常、业务异常、兜底异常，统一返回 `Result`
  - 目前只处理了 `IllegalArgumentException`；`MethodArgumentNotValidException`（`@Valid` 失败）和兜底 `Exception` 还没加
- [x] 把 `@Valid` 加到请求参数上，试试传空标题

**验收**：故意传非法参数，返回的是你的 JSON，不是 Spring 默认的错误页。

> 备注：`@Valid` 校验失败目前会走 Spring 默认的 400，body 不是 `Result`。补 handler 时一起处理。

### M2 登录与权限（3～5 天，全项目最难）✅ 已完成（2026-10-24）

> 目标：能用一个账号登录，登录后能访问后台接口，未登录返回 401 JSON。

#### T2.1 用户实体与查询

- [x] `User` 实体映射 `users` 表
- [x] `UserMapper` 提供"按用户名查人"
- [x] 确认 `password_hash` 字段名和实体对得上

#### T2.2 实现 UserDetailsService

- [x] 建 `service` 包，写一个类实现 `UserDetailsService`
- [x] `loadUserByUsername` 里查数据库，查不到抛 `UsernameNotFoundException`
- [x] 返回的 `UserDetails` 里带上密码哈希和权限
- [x] 注册 `BCryptPasswordEncoder` 这个 Bean

**验收**：启动不报错，日志里不再出现 `Using generated security password`。

**这一步的坑**：定义了 `UserDetailsService` 却没给 `PasswordEncoder`，启动会报错。两个必须成对出现。

#### T2.3 初始化管理员账号

- [x] 用 `CommandLineRunner`：启动时检查 `users` 表，为空则插入一个管理员
- [x] 密码用 `passwordEncoder.encode(...)` 加密后再存
- [x] 账号密码写在 `application.yml` 或环境变量里，别硬编码在代码里

**验收**：启动后 Navicat 里能看到一行，密码是 `$2a$...` 这种哈希，不是明文。

#### T2.4 写登录接口

- [x] 注册 `AuthenticationManager` Bean
- [x] `POST /api/auth/login`：调 `authenticate(...)`，成功后**必须把 SecurityContext 存进 Session**
- [x] 失败返回 401 + 统一 JSON
- [x] `GET /api/auth/me`：返回当前登录用户
- [x] `POST /api/auth/logout`：销毁 Session

**验收**：用 IDEA 的 `.http` 发登录请求，响应带 `Set-Cookie`；再发 `/api/auth/me`，返回用户信息。

**最容易漏的一步**：手动认证成功后，Security 不会自动帮你把身份存进 Session，必须显式调用 `SecurityContextRepository` 保存。漏了就会"登录成功但下一个请求还是未登录"。这条到时候单独处理。

#### T2.5 收窄权限规则

- [x] `/api/admin/**` → 需要登录
- [x] `/api/auth/me`、`/api/auth/logout` → 需要登录
- [x] `/api/**` 其余 → 放行
- [x] `/error`、`/uploads/**` → 放行

**验收**：无痕窗口访问 `/api/admin/xxx` 返回 401 JSON；登录后返回 200。

#### T2.6 401 / 403 返回统一 JSON

- [x] 配 `AuthenticationEntryPoint`（未登录 → 401）
- [x] 配 `AccessDeniedHandler`（无权限 → 403）
- [x] 两者都输出 `Result` 格式

**验收**：未登录访问后台接口，`response.data.message` 有值，不是 `undefined`。

> **M2 完成记录**：登录、`/me`、`/logout`、401/403 统一 JSON 全部验证通过。
> 遗留两项已记入接口文档第 9 节：登录失败限流（429）、账号禁用（403）。

## 7. 三条铁律

1. **一次只改一个变量**。同时改配置和代码，出错时你不知道是谁的锅
2. **先让它跑，再让它好**。第一个接口允许 Controller 直接调 Mapper，第二个再抽 Service
3. **改接口先改文档**。文档和代码不一致，三天后你自己都分不清哪个是对的
